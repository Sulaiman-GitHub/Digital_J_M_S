Notes

  • Only vacancies that take applications here show a count; the number links to the applicants. "N new" counts applications nobody has moved out of Submitted.
  • The status control offers only the moves the rules allow from the current status. Rejected and withdrawn are final, and the control is replaced by a sentence saying so.
  • The note is optional, at most 1000 characters, and the applicant can read it (the screen says so).
  • Download CV gives the copy the applicant sent, not their current CV. Every download is logged.
  • The employer sees the profile as it was when the person applied, with a clear label.
  • States: loading skeletons, "No one has applied yet" and "No applicants with this status", error with Retry, and a plain message when the application belongs to someone else.
