Notes

  • Banner colour is never the only signal: each state has a heading, an icon and text. Danger banners are announced at once (role alert); the others politely (role status).
  • Rejected and suspended banners show the admin's reason in a quoted block. The employer cannot reply in the app yet.
  • Disabled publishing buttons use aria-disabled and the explanation is linked with aria-describedby, so screen readers read why.
  • The profile is read-only while pending or suspended; approved profiles warn that renaming or changing the registration number triggers a new check.
  • Submit shows a confirm dialog: "Submit for verification? You cannot edit while we check it."
  • Submitting needs a verified email address: if it is not, the Submit button is disabled and says so, next to the existing verify-email banner.
