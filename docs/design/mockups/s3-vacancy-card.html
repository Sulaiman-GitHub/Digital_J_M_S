Anatomy and rules

  1. Title 18 px semibold, text colour. Max 2 lines then ellipsis.
  2. Company in secondary colour. Shield icon only for an approved employer, with an accessible name "Verified employer".
  3. District with a pin icon (icon is decorative; the word carries the meaning).
  4. Job type pill: Full-time, Part-time, Contract, Internship, Graduate trainee, Volunteer.
  5. Salary only if the employer chose to show it. Integer UGX with thousands separators.
  6. Posted relative time ("today", "3 days ago", "2 weeks ago"), shown in Africa/Kampala time. "Closes in N days" in warning colour when ≤ 3 days remain.
  • The whole card is one link (one tab stop). Hover and focus show a primary border; focus also shows the outline ring.
  • External-link vacancies show an "Employer site" badge so seekers know before opening.
  • No logos or images in the MVP card (low data).
