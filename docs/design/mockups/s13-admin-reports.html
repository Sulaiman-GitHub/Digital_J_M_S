Notes

  • Anyone logged in can report a live vacancy once. Anonymous visitors are asked to log in first. A vacancy the person already reported shows "You reported this vacancy".
  • "Something else" needs details; the other reasons do not. The reporter is never shown to the employer.
  • The admin list opens on Open reports, newest first, with filters for Actioned, Dismissed and All. Each card shows the vacancy, the company, the reason, the reporter's words, and how many open reports the vacancy has.
  • Review shows the vacancy as people see it. Dismiss keeps the vacancy live. Close vacancy removes it from public search at once and settles every open report about it. The suspend option is offered only for an approved employer and needs a reason.
  • States: loading skeletons, "No open reports" empty state, error with Retry.
