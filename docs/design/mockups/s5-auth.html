Notes and rules

  • One primary action per screen. Forms validate on submit, then on change; server field errors appear under the field, other errors in the alert above the form.
  • Role choice uses two large radio cards (no default would be safer, but most users are job seekers, so "Looking for work" is preselected). Admin is never offered.
  • Show/Hide toggles the password field; no "confirm password" field (show/hide makes typos visible).
  • Login never says whether an email exists. Forgot password always shows the same confirmation.
  • After login: go back to the page that asked for login (same-site paths only), otherwise "My account".
  • Verify banner: only for logged-in, unverified users. Resend shows a toast; "already verified" and "too many requests" show their messages.
  • Phone header: brand + menu button (keyboard and screen reader friendly, Escape closes). Desktop: inline links + user menu. Job seeker bottom nav comes with the profile screens.
  • Inputs 16 px, autocomplete set (email, current-password, new-password), tap targets 44 px.
