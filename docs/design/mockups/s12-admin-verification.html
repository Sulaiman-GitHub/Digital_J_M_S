Notes

  • The queue opens on Pending. Filters are toggle pills; the count of the current filter comes from the page details. States: loading skeleton, empty ("No employers waiting"), error with Retry.
  • Actions depend on status: pending shows Approve and Reject; approved shows Suspend; suspended shows Approve again; draft and rejected show "Waiting for the employer".
  • Reject and Suspend open a dialog with a required reason. Approve needs no dialog. The server message is shown if a decision was already made by another admin (409).
  • The checklist only marks what was provided (tick or cross, with text). It never claims the details are true.
  • Timeline entries show who, when and the reason. Admin emails are visible to admins only.
